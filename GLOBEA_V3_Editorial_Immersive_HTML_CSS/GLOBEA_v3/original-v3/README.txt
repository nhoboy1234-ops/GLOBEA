GLOBEA V3 — Immersive Editorial Travel (HTML + CSS only)

1. Mở index.html để xem trang chủ tràn màn hình có thanh tìm kiếm trong ảnh.
2. Kéo xuống để xem bố cục ảnh 2/3, tạp chí nền sáng, ảnh fullbleed, lịch sử, ẩm thực và gợi ý du lịch.
3. Mở từng trang hoi-an.html, kyoto.html và amalfi.html từ trang chủ.
   • Hội An: hero tràn màn hình, ấm áp.
   • Kyoto: 2/3 ảnh kết hợp chữ nền sáng.
   • Amalfi: ảnh toàn khung và bảng thông tin sáng nổi trên ảnh.
4. Trên trang địa điểm, nhấn tab dọc 'LÊN LỊCH TRÌNH' bên phải để mở bảng.
5. Chưa dùng JavaScript, chưa có tính năng tạo lịch trình tự động.

Các file HTML và style.css để cùng thư mục; ảnh nằm trong assets/.
Ảnh là minh họa giao diện demo, không đại diện giá/lịch hoạt động thực tế.
